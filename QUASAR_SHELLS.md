# Quasar Shells for LC Housing

## Important

Quasar Shell Creator does not use one universal public shell-name list. Each shell exported from the Quasar Shell Creator can have a server-specific model name and entry offsets. The exported code is the authoritative source for that shell.

Do not add a shell model here until its resource is installed and the model is streamed on the server.

## How to add a Quasar shell

1. Open Quasar Shell Creator with `/shellcreator`.
2. Select or create the shell.
3. Save it and copy the generated configuration code.
4. Add the generated shell entry to `Config.Shells` in `config.lua`.
5. Copy the model name into `Config.Defaults.shell` only if you want it to be the default for new properties.
6. Restart LC Housing and verify the preview, entry point, exit point, and collision in-game.

## Entry template

Replace the placeholder values with the exact values generated by Quasar:

```lua
{
    model = 'QUASAR_EXPORTED_MODEL_NAME',
    label = 'Quasar Shell - Custom Name',
    description = 'Exported from Quasar Shell Creator',
    entry = { x = 0.0, y = 0.0, z = 0.0, h = 0.0 },
    preview = {
        camera = { 0.0, -4.0, 2.5 },
        target = { 0.0, 0.0, 1.5 },
        fov = 76.0
    }
}
```
